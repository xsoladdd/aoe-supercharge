# Agent of Empires: Supercharge

An opinionated parent/child dashboard for Claude Code, built on top of [Agent of Empires](https://github.com/agent-of-empires/agent-of-empires).

**Status: Phase 0 (discovery) is done. The spec is waiting for approval. No application code yet.**

- [SPEC.md](SPEC.md) covers architecture, CLI, config, ledger, stage machine, API, UI, install and tests. Section 2 lists the open decisions.
- [docs/phase0/aoe-1.17.2-source-notes.md](docs/phase0/aoe-1.17.2-source-notes.md) holds AoE API facts read from source.
- [fixtures/aoe/1.17.2/](fixtures/aoe/1.17.2/) holds redacted responses recorded from a real AoE 1.17.2.

Platforms: macOS and Linux. Required: git, tmux, Node 24 LTS, Claude Code, Agent of Empires, glab. Install steps arrive in Phase 1.
