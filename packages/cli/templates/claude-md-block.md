## Supercharge

This repository is coordinated with Agent of Empires: Supercharge.

- The project's control chat spawns one worker session per task with `supercharge task new`.
- Workers report progress with `supercharge stage`, `supercharge plan` and `supercharge ask`. Run `supercharge whoami` to see your role.
- Details live in the `supercharge-control` and `supercharge-worker` skills under `.claude/skills/`.
