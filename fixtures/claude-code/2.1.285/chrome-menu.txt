  Claude in Chrome

  Claude in Chrome works with the Chrome extension to let you control your browser directly from Claude Code. Navigate
  websites, fill forms, capture screenshots, record GIFs, and debug with console logs and network requests.

  Status: Enabled
  Extension: Installed

  ❯ Select browser…
    Manage permissions
    Reconnect extension
    Enabled by default: Yes

  Usage: claude --chrome or claude --no-chrome

  Site-level permissions are inherited from the Chrome extension. Manage permissions in the Chrome extension settings
  to control which sites Claude can browse, click, and type on.

  Learn more: https://code.claude.com/docs/en/chrome
